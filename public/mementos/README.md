# PDFs originais dos mementos

Coloque aqui os PDFs originais do Maciel ("Pernambuco Imortal"), um por matéria,
nomeados pela **sigla da disciplina** em maiúsculo:

```
/public/mementos/GRAPP.pdf
/public/mementos/GPGA.pdf
/public/mementos/IG.pdf
/public/mementos/LPMO.pdf
...
```

A aba "📕 PDF original" de cada matéria carrega automaticamente `/{sigla}.pdf`.
Se o arquivo não existir, a aba mostra um aviso de "ainda não adicionado".
